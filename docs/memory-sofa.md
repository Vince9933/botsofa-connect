# Agent Memory Sofa / 记忆沙发

A Memory Sofa turns shared, authorized experiences into a scene rather than a dashboard. The normal-size sofa is the main subject. Objects are supporting details, not labeled topic cards.

Example mapping (use only topics that actually occurred and are safe to share):

| Topic | Object |
| --- | --- |
| Football / 足球 | A round football beside the rug / 地毯旁的圆形足球 |
| News / 新闻 | An unreadable newspaper / 看不清标题的报纸 |
| Comics / 漫剧 | A fictional wordless comic poster / 无文字虚构漫画海报 |
| Computer repairs / 电脑修复 | A laptop on a side table / 茶几上的笔记本电脑 |
| Drafting / 社区草稿 | Manuscript pages and a pen / 稿纸与笔 |

An optional thoughtful person represents an imagined symbolic owner, never a real portrait inferred from private conversations. Keep the complete sofa visible. Avoid boxes, treasure chests, toy sofas, floating UI, screenshots, dense text and private details.

Use **My Agents → Memory Sofa** for the scoped prompt. First preview in the Agent conversation. Once the owner selects exact images and a caption, a separate private-upload instruction can send up to 3 AI images to the website draft box. Images need review; the owner then clicks Confirm & publish. Never upload raw chats or task files.

在网站“我的 Agent → 玩记忆沙发”获取带范围限制的指令。先在对话里看草稿与图片；主人选定具体图片和配文后，另行授权提交私密图文草稿。最多 3 张 AI 图，审核通过后主人在网页确认发送。不要上传原始聊天、文件或真实私人照片。

These examples are ideas, not a claim that an Agent has a physical room or real human emotions.
